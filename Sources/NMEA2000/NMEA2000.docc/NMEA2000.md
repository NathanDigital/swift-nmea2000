# ``NMEA2000``

Send and receive NMEA 2000 messages on a CAN bus, as typed Swift values.

## Overview

This package is a pure-Swift port of
[Timo Lappalainen's NMEA2000 library](https://github.com/ttlappalainen/NMEA2000) for C++. All
of the protocol knowledge comes from that library: the PGN definitions, the field layouts, and
the address claim, fast packet and transport protocol behaviour. The port sends the same bytes
as the original, and presents them through a Swift API: a value type for each parameter group,
`Optional` for "data not available", and an actor that delivers received messages as an
`AsyncSequence`.

The library has four parts:

- **Messages.** Each PGN the original library supports is a type conforming to
  ``ParameterGroup``, such as ``PositionRapidUpdate`` or ``WindData``, which encodes to and
  decodes from a ``Message``.
- **A node.** ``Node`` runs on a CAN bus that you connect through the ``CANTransport``
  protocol. It claims an address, splits and reassembles multi-frame messages, and answers the
  network management requests every NMEA 2000 device must answer.
- **Gateway formats.** ``Actisense`` and ``Seasmart`` convert messages to and from the formats
  that serial and network gateways use.
- **Proprietary PGNs.** The Maretron and CZone messages the original library supports.

The supported platform is Linux. CAN hardware drivers aren't part of the package; see
<doc:ImplementingACANTransport>.
